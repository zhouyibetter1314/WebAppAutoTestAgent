# ADR 0001：本地单 Agent 与共享服务

状态：接受。

课程要求自主实现策略，且团队规模为 2–4 人。选择 LangGraph 作为状态管理工具，自行实现解析、计划、观察、决策、验证与恢复。暂不引入预制浏览器 Agent 或多 Agent 协作协议。

Vue 图形工作台与 CLI 共用 FastAPI 应用服务/Runner。Python src 包布局、SQLite、JSON 事件、运行文件夹使小团队易调试；代价是当前不支持分布式、多用户与横向并发。

锁文件与 gitlink 固定依赖。子模块仅保存上游内容，部署覆盖放主仓库。先完成 4gaBoards 环境，其他两个目标延后部署。

图状态不持有浏览器句柄；异常或取消后不恢复重放副作用。每次重新运行创建新 run ID，方便比较和审计。
