\section{项目内容}
\begin{frame}{项目内容与交付范围}
\begin{enumerate}
\item \textbf{场景管理：}保存自然语言需求、前置条件和检查点，关联应用与测试账号配置。
\item \textbf{自主执行：}观察页面、生成动作、调用浏览器工具，处理定位失败与运行中断。
\item \textbf{结果验证：}逐项核对检查点，区分通过、失败与无法判定，保存证据。
\item \textbf{图形工作台：}展示运行时间线、步数和截图，支持取消、历史查询与报告下载。
\item \textbf{实验与交付：}形成可运行源码、部署说明、实验记录及课程报告。
\end{enumerate}
\vfill
\small 项目边界：本地单用户、任务顺序执行；多用户权限和分布式调度暂不列入本期。
\end{frame}
