\begin{frame}{自主测试流程与结果判定}
\begin{enumerate}
\item \textbf{解析与规划：}保留用户原文，固定预期检查点，生成可调整的执行计划。
\item \textbf{观察与执行：}读取 DOM/ARIA 与截图，生成结构化动作，通过校验后执行。
\item \textbf{验证与恢复：}引用页面观察核对检查点，失败时在剩余预算内有限重试。
\item \textbf{结束与报告：}结束前复核未完成项，保存结论、时间线、截图与 Trace。
\end{enumerate}
\begin{block}{结论与证据对应}
PASS：所有检查点均满足；FAIL：有可靠证据表明检查点不满足；INCONCLUSIVE：执行异常或证据不足。
\end{block}
\small LangGraph 管理流程和状态，测试策略由项目自主设计；模型的完成声明不能直接替代检查点验证。
\end{frame}
