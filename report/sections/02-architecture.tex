\begin{frame}{单 Agent 状态图与判定策略}
\begin{enumerate}
\item 解析：保留原文，生成前置条件、目标、独立检查点。
\item 规划与观察：生成计划，读取 DOM/ARIA，保存页面截图。
\item 决策与执行：校验结构化动作，在分发前计入预算。
\item 验证与恢复：引用观察原文和证据编号；定位失败后有限恢复。
\item 汇总与收尾：生成报告、保存 Trace、关闭浏览器和模型连接。
\end{enumerate}
\begin{block}{判定规则}
全部检查点满足 $\Rightarrow$ PASS；可靠反例 $\Rightarrow$ FAIL；执行异常或证据不足 $\Rightarrow$ 无法判定。
\end{block}
\end{frame}
